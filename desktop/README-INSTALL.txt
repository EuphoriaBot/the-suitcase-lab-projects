THE SUITCASE LAB — CINEMATIC EXTERIOR V2

1. Extract this ZIP into D:\The Suitcase Lab\desktop, merging src folders.
2. Replace TimekeeperIntro.tsx and timekeeper-intro.css.
3. The zip adds archive-exterior.webp and two door cutouts into assets/timekeeper.
4. Do NOT replace TimekeeperRoom.tsx, timekeeper-room.css, TimekeeperEntry.tsx, App.tsx or SQLite files.
5. Keep your existing src/renderer/src/assets/timekeeper/room-scene.webp.
6. Run npx prettier --write src/renderer/src/features/timekeeper/TimekeeperIntro.tsx src/renderer/src/features/timekeeper/timekeeper-intro.css
7. Run npm run typecheck && npm run lint && npm run dev.
